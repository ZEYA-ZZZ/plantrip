ซิงก์ข้อมูลผ่าน GitHub

เก็บข้อความที่แก้ไข เวลา ลิงก์ Amap รูป และสถานะ "ไปแล้ว" ไว้ใน repo ของคุณ เพื่อเปิดดูได้ตรงกันทุกอุปกรณ์

วิธีตั้งค่า (ทำครั้งเดียว)
  1. สร้าง repo ใหม่บน GitHub (แนะนำ Private) และติ๊ก "Add a README" เพื่อให้มี branch main
  2. ไปที่ Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. เลือก Repository access: Only select repositories → เลือก repo นั้น
  4. Permissions → Repository permissions → Contents: Read and write
  5. คัดลอก token มาวางด้านล่าง (ทำซ้ำบนทุกอุปกรณ์ที่จะใช้)
token เก็บไว้ในเบราว์เซอร์เครื่องนั้นเท่านั้น อย่าใช้บนเครื่องสาธารณะ
